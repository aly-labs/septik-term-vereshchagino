# Сайт «Септики ТЕРМИТ под ключ в Верещагино»

Одностраничный продающий сайт: каталог оборудования ТЕРМИТ, подбор, калькулятор
стоимости, монтаж под ключ, формы заявок с интеграцией в n8n.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница (все 10 блоков) |
| `css/styles.css` | Оформление (тёмно-зелёная палитра, Manrope) |
| `js/config.js` | Контакты, бренд, населённые пункты (без секретов) |
| `js/main.js` | Калькулятор, фильтры, формы, анимации |
| `data/catalog.json` | **Прайс и модели — править здесь, отдельно от дизайна** |
| `server.py` | Локальный сервер + приём заявок + прокси в n8n |
| `privacy.html` | Политика конфиденциальности (заготовка) |
| `leads.jsonl` | База заявок (создаётся автоматически) |
| `img/` | Иллюстрации (заменить на реальные фото) |

## Как запустить

Требуется Python 3 (проверено на 3.11).

```bash
python server.py
```

Открыть: **http://localhost:8000**

Сайт рассчитан на работу через сервер: без него не отправляются формы и не
подгружается каталог (`data/catalog.json`). Открывать `index.html` двойным
кликом нельзя.

## ЧПУ страниц каталога

URL вида `/catalog/termit-profi-2-0` открывают страницу модели:
подставляются `<title>` и `<meta description>`, страница прокручивается к карточке.
Соответствие URL и моделей задано полем `slug` в `data/catalog.json`.

## Как обновить цены

Правите только `data/catalog.json` — карточки и калькулятор подхватят изменения сами.

- `price: 39000` — цена, `price: null` — «Уточнить стоимость»
- `priceConfirmed: false` — на карточке появится метка «Цена по запросу»
- `users`, `usersText`, `purposes`, `type` — участвуют в фильтрах и калькуляторе

## Настройка заявок (n8n / Telegram / CRM)

1. Создайте webhook в n8n (Webhook node → POST → JSON body).
2. Запустите сервер с адресом вебхука в переменной окружения:

   **PowerShell (Windows):**
   ```powershell
   $env:N8N_WEBHOOK_URL = "https://ваш-домен/webhook/id"
   python server.py
   ```

   **Linux/macOS:**
   ```bash
   N8N_WEBHOOK_URL="https://ваш-домен/webhook/id" python3 server.py
   ```

3. Необязательный заголовок авторизации: `N8N_AUTH_HEADER="Bearer секрет"`.
4. Если адрес не задан — заявки всё равно сохраняются в `leads.jsonl`
   (ни одна не теряется), а в консоль пишется предупреждение.

**Важно:** адрес вебхука и ключи живут только на сервере, в переменных окружения.
Их нет в коде браузера.

Пример полезной нагрузки, которую получает n8n:

```json
{
  "receivedAt": "2026-10-12T15:04:00",
  "type": "calculator",
  "model": "ТЕРМИТ Профи 3.0",
  "name": "Иван",
  "phone": "+7 (999) 123-45-67",
  "city": "Верещагино",
  "comment": "Глина, УГВ высокий",
  "answers": { "Объект": "Частный дом", "Пользователи": "5–6 человек" },
  "page": "http://localhost:8000/"
}
```

## Заявки на Яндекс.Диск (таблица)

Сервер сам дописывает каждую заявку в Excel-таблицу и загружает её
на Яндекс.Диск — файл **«Заявки с сайта.xlsx»** в корне диска, можно
открывать как обычную таблицу.

1. Получите токен Яндекса (один раз):
   - Создайте приложение: **https://oauth.yandex.ru/client/new** — название
     любое, платформа «Веб-сервисы», Redirect URI
     `https://oauth.yandex.ru/verification_code`, права: «Яндекс Диск»
     (чтение и запись). Запомните ClientID и Client secret.
   - Выполните: `python yadisk_token.py` — пройдите авторизацию в браузере
     и получите токен.
2. Запускайте сервер с токеном:

   ```powershell
   $env:YADISK_TOKEN = "полученный-токен"
   python server.py
   ```

   Без токена таблица всё равно ведётся локально (файл `Заявки.xlsx`
   в папке проекта). Токен хранится только в переменной окружения сервера,
   в браузерный код он не попадает.

Название файла на диске можно поменять в `server.py` (переменная `YADISK_REMOTE`).

## Публикация в интернет

Домен, DNS и хостинг — на ваш выбор. Варианты:

1. **Полный функционал (рекомендуется):** разместите файлы проекта на VDS
   (или любой PaaS) и запустите `server.py` как службу. Заявки уйдут в n8n,
   ЧПУ и каталог заработают. Рекомендуется HTTPS.
2. **Статический хостинг (Netlify, GitHub Pages и т. п.):** выгрузите файлы,
   но `/api/lead` не заработает. Для приёма заявок понадобится либо
   серверная функция (Serverless Function) с тем же логикой, либо сервис
   вроде Web3Forms. Каталог и калькулятор при этом работают.

После публикации:

- замените `https://example.ru/` в `index.html` (canonical), `robots.txt`, `sitemap.xml`;
- подключите аналитику (Яндекс.Метрика) — сайт уже имеет для неё всё необходимое;
- отправьте sitemap в Яндекс.Вебмастер.

1. **Телефон компании** — сейчас заглушка `+7 (342) 200-45-67` в `js/config.js`;

5. **Тарифы на доставку, земляные работы и монтаж** — сейчас калькулятор и сайт
   сознательно не выдумывают цифры: «Итоговую сумму считаем индивидуально»;
6. **Размеры моделей** — сейчас «по техпаспорту» (поле `dims`);
7. **Название компании / ИП, ИНН, адрес** — для футера и политики конфиденциальности;
8. **Фотографии оборудования и реальных монтажей** — заменить `img/hero.svg` и
   `img/product.svg`, сохранить в WebP/AVIF, если есть;
9. **Текст политики конфиденциальности** — в `privacy.html` стоит заготовка;
10. **Домен и хостинг** — для публикации.
